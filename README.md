# Simple Supabase-Like Dashboard (Vanilla)

A lightweight Supabase-inspired dashboard built with plain HTML, CSS, and JavaScript — no frameworks, no build tools, no extra files.

### This project focuses on clarity and simplicity, using:

- ✅ Single plain CSS file for styling
- ✅ Single vanilla JavaScript file for logic
- ✅ No external libraries, bundlers, or dependencies

### Perfect for:

- Learning how dashboards work under the hood
- Prototyping admin panels quickly
- Using as a starter template for backend integration (Supabase, Firebase, REST APIs, etc.)
